1: # QuestarrNG translation glossary
2:
3: Use these meanings consistently across interface copy, help text, notifications, and API summaries.
4:
5: | Source term | Meaning and translation guidance |
6: |---|---|
7: | Game | A catalog item in the user's game library. Do not translate a game's actual title. |
8: | Release | A downloadable release record returned by an indexer or provider. Preserve the release's original title and group tag. |
9: | Update / patch | A later game version or corrective package. Keep it distinct from a full game release. |
10: | DLC / expansion | Add-on content associated with a base game. Preserve vendor product names. |
11: | Pack / add-on | A grouped download or bundle when the product context does not specifically mean DLC. |
12: | Wanted | A user-selected game they intend to acquire; it is a library status, not a generic desire. |
13: | Library import | The operation that matches downloaded files to a game and moves or records them in the library. |
