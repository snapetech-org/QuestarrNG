QuestarrNG adds translated interface text in twelve languages with English fallback while preserving game titles and external values. Fixed server notifications for delayed releases without a date, available content, and interrupted or removed downloads awaiting import now have translated titles and messages. Another 58 fixed API error details from account, discovery, content-request, asset, and URL-validation routes now have translations, with one parameterized domain-list error retaining its runtime values. These new notification and error translations still need native-speaker review.
