Export and preview a metadata-only library catalog, import new games without replacing existing records, and select discovery games for a bulk add. Metadata refresh preserves existing details unless replacement is explicitly enabled. Library scans retain progress across restarts, and qBittorrent supports an explicit Bearer API-key mode. rTorrent connection diagnostics redact credentials.
